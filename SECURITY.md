# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Blocky is a privacy-first application that handles phone call screening entirely on-device without any cloud backends or external telemetry.

If you discover a security vulnerability or privacy concern, please do **NOT** open a public issue. Instead, report it directly via:

- **Email:** `prismaticamedia@gmail.com`

Please provide:
- A description of the issue
- Steps to reproduce
- Affected device model and Android OS version

We will review reports promptly and publish patches in subsequent release builds.
